# Toolhead Manager

A Moonraker + Mainsail extension for managing multiple toolheads (spindle, extruder, laser, drag knife, etc.) in Klipper.

## Project Goals
- Provide UI tab in Mainsail for toolhead selection/management.
- Expose Moonraker API endpoints for toolhead state.
- Integrate with Klipper macros for tool changes.

## Baseline Versions
- Klipper: v0.13.0-253-g96c3ca16
- Moonraker: v0.9.3-104-g52e31586
- Mainsail: v2.14.0

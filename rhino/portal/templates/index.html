    Spare pins for new tool outputs

    Existing outputs a new powered tool may drive instead of using a new pin.

    System hardware

    Hardware on other board pins, not plugged into the umbilical: enclosure fans and lights, pumps, sensors.

    System hardware

    Hardware that belongs to the machine rather than a tool: enclosure fans and lights, air and vacuum pumps, door switches, sensors. It is wired to board pins that are not on the umbilical, works whatever tool is mounted, and gets the same guided set-up as a tool control.

    Tasks

    Task Library

    Library tasks are task definitions that are not tied to anything yet. A Task Book groups library tasks under one name: assign the book to a toolhead (or the whole machine) and it carries all of its tasks there. Those tasks stay linked to the library, so editing a library task updates every copy.

How the software fits together

The Rhino's software runs on a small computer beside the machine, the host: a Dell OptiPlex 7050, or a Raspberry Pi on older builds. You use it from a browser on any computer, tablet or phone on the same network.

  • Klipper moves the machine and runs the macros: tool swaps, job start and end, and every safety check. It decides what is mounted, and records it in variables.save; no screen can change that except through Klipper's own swap wizard.
  • Moonraker passes messages between Klipper and the screens: the machine's status, commands, and the job files.
  • Rhino Studio is the main screen. It sends Klipper only commands it has checked, and asks before anything that moves the machine or powers a tool. It slices models in your browser, or on the host with PrusaSlicer if you choose that.
  • The Rhino Portal keeps what Klipper doesn't: the tools you add, system hardware, maintenance, backups, slicing profiles and updates. Studio's Assets, Care and Settings screens use it. It writes custom_tools.cfg from your tools, and asks Klipper to restart only when no job is running. It still has its own pages at port 5000.
  • Mainsail is still installed and works as before; you don't need it.

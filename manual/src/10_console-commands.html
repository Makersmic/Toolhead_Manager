Console commands

Everything the portal does can also be typed in the Mainsail console. Lines starting rhino: are the tool manager's replies; nothing changes if a command is refused.

Managing tools

CommandWhat it does
ADD_TOOLHEAD NAME=FoamWire KIND=HOT_WIRE PIN=PB1Add a powered tool on a new pin
ADD_TOOLHEAD NAME=Needle KIND=NEEDLE POWER_PIN=SPINDLE_SPEEDAdd a powered tool on a shared output
ADD_TOOLHEAD NAME=Wide KIND=PRINT_HEAD BASE=BlockOne NOZZLES=0.6,1.0Add a print-head clone with new nozzle sizes
EDIT_TOOLHEAD NAME=FoamWire CAP=0.4 MAX_ON_S=300Change limits (also MIN=, IDLE=, S_MAX=, DEFAULT_POWER=)
EDIT_TOOLHEAD NAME=FoamWire MATERIAL=FOAM_EPS POWER=0.45 FEED=280 ZOFF=0Add or change a material
EDIT_TOOLHEAD NAME=FoamWire DELMATERIAL=FOAM_XPSRemove a material
RENAME_TOOLHEAD NAME=FoamWire NEWNAME=HotWireRename
REMOVE_TOOLHEAD NAME=FoamWireRemove (asks you to confirm)
LIST_TOOLHEADSEvery tool with slot, type and materials
TOOLHEAD_PINSWhich connector pins are free, used or reserved
CHECK_TOOLHEADSRe-check the registry against the config and regenerate custom_tools.cfg
RESTART_FOR_TOOLSRestart Klipper to load tool changes (refused during a job)
TOOLS_MENUReminder of where to add, edit and remove tools

Running the machine

CommandWhat it does
START_TOOL_SWAPGuided tool change
RESTORE_TOOLConfirm the mounted tool after a restart
SET_TOOLHEAD TOOLHEAD=<tool> MATERIAL=<material>Select tool and material for the next job
LASER_JOB_SETUP / CNC_JOB_SETUP / DRAGKNIFE_JOB_SETUP / TOOL_JOB_SETUP FILE=<name>.gcodeGuided job setup for that tool
TOOL_RESUMEResume a paused non-print job
M3 S<value> / M5Mounted tool on / off
SET_TOOL_POWER POWER=<0–1>Set an added powered tool's output (fraction of its cap)
FILAMENT_CHANGEGuided filament change
BED_COOLDOWNStaged, material-aware bed cooldown
EMERGENCY_STOPAll tool power off (see Safety systems)
BACKUP_CFG MSG=<note>Push the config folder to your GitHub backup
SWITCH_T0 / SWITCH_T1SwitchFly: select filament path 1 or 2
Z_TILT_ADJUSTTram the bed with the three Z motors (home first)
CALIBRATE_ESCGuided spindle ESC throttle calibration (bit removed)
PM_STATUSList maintenance that is overdue or due soon (live)
PM_REMINDERShow the start-up maintenance pop-up again

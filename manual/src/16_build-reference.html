Build reference

The printable parts, CAD (STEP) files and assembly drawings are in the Rhino-3d-Printer repository. Print structural parts in ABS or ASA.

Frame

The frame is 2020/2040/2060 aluminium extrusion with 2″ × ¼″ aluminium flat bar across the top; some components mount straight to the flat bar, using printed drilling templates for hole placement.

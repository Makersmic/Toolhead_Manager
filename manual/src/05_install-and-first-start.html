Install and first start

The Rhino software installs from a menu on the Pi, in the style of KIAUH: you upload the zip in Mainsail, type three short commands, then pick numbered options. Every option says what it is about to do and asks before changing anything, and every install backs up your config folder first.

Before you start: the printer idle, and a print head (BlockOne or SwitchFly) mounted. The first start homes the machine, and only a print head can home Z safely. You need the Pi's address (the one you open Mainsail with) and its login and password; on most Klipper installs the login is pi.

  1. Upload the zip. In Mainsail open Machine, press Upload and choose rhino-config-1.3.5.zip. Check the file list shows exactly that name; if the browser renamed it (... (1).zip), fix the name and upload again.

  2. Open a terminal on the Pi. On Windows open PowerShell, on a Mac open Terminal, and log in with your login and the Pi's address. Answer yes the first time, then type the password (it stays invisible).

    ssh pi@192.168.1.50

  3. Open the Rhino menu. Paste one line at a time:

    cd ~/printer_data/config
    unzip -o rhino-config-1.3.5.zip -d ~/rhino-1.3.5
    bash ~/rhino-1.3.5/rhino.sh

    If unzip is missing, run sudo apt install -y unzip first. The menu looks like this:

    /==========================================================\
|             ~~~~ [ Rhino Tool Manager ] ~~~~             |
|----------------------------------------------------------|
| Installed version : not installed                        |
| This folder has   : 1.3.5   (/home/pi/rhino-1.3.5)       |
| Portal            : not installed                        |
|----------------------------------------------------------|
| 1) Preview the install       (changes nothing)           |
| 2) Install / update from this folder                     |
| 3) Install a new zip  (unpack, preview, install)         |
| 4) Undo an install            (pick a backup)            |
| 5) Portal status and recent log                          |
| 6) Restart the portal                                    |
|                                                          |
| Q) Quit                                                  |
\==========================================================/
Perform action:

  4. Preview: option 1. It checks your login and config folder, whether a job is running, whether something else uses port 5000 and whether an earlier portal is installed, then lists every step without changing anything. It ends with Dry run finished, or with STOPPED: and what to do.

  5. Install: option 2, then y. It asks for the password once and works through eight stages, each ending in OK:

    • backs up the config folder to ~/rhino-backup-<date>;

    • copies the new files, never touching variables.cfg, variables.save or the tool files the portal generates;

    • keeps the SAVE_CONFIG section at the bottom of printer.cfg, and never doubles it;

    • fixes /home/pi paths if your login is different;

    • installs Flask from the Pi's own packages, plus Waitress when it is available;

    • replaces any earlier portal service (its settings are saved in the backup), starts the portal at every boot, and checks it answers.

    It finishes with the portal's address, http://<printer address>:5000. Afterwards the menu is always at bash ~/rhino-manager/rhino.sh.

  6. First start, in Mainsail. With the print head still mounted:

    • Run FIRMWARE_RESTART and wait for Ready. A red box names the file and line Klipper did not accept.

    • Answer the pop-up asking which tool is mounted (or run RESTORE_TOOL).

    • Run CHECK_TOOLHEADS. When the console line starting rhino: says OK, press Restart now.

  7. Check Z before the first job. After any update, check Z (the Rhino uses gear_ratio: 2:1 on all three Z steppers). Home with the print head, move Z 10 mm and measure it, then run Z_TILT_ADJUST and re-check your Z offsets.

A good place to stop is after the preview (nothing has changed) or after the first start. Avoid stopping between the install and the first start.

Updating: upload the new zip, open the menu, choose 3 and pick it. It unpacks the zip, shows the preview and asks whether to install; answer y, then do the first start again. Your tools, photos and maintenance history are kept. Undoing: option 4 lists your backups (the oldest is your setup from before the first install), previews the restore and asks first; anything added since is moved aside to ~/rhino-undone-<date>, not deleted.

Never home Z with the laser, spindle or drag knife mounted. Homing Z brings the bed up to the tool. From 1.3.5 their macros refuse to, and jobs end with the bed lowered to the safe park height so the machine can always home X and Y after a restart.

The portal has no login. Anyone who can reach port 5000 can add or remove tools, but it cannot run G-code and refuses to restart Klipper during a job. Keep it on your home network, or start it with --host 127.0.0.1 and reach it through an SSH tunnel.

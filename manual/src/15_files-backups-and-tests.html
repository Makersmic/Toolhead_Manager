Positions. Where the head parks, where it goes for a tool swap, how far the bed lowers before a swap or park, the lowest the Set Z zero window goes, and where the prime line starts and how long it is are all in myrhino/positions.cfg. Change a number, save, then FIRMWARE_RESTART; every macro (and Mainsail's own pause park) uses the new number. Type RHINO_POSITIONS in the console to list them - it also checks each one against the travel limits in printer.cfg, and the same check runs at every start with any problem shown in red. Updates never overwrite this file. The travel limits themselves, where Z homes and the probe offset stay in printer.cfg because Klipper needs them; the paper test goes to the probe's spot worked out from those.

Backups. BACKUP_CFG MSG=<note> pushes the config folder to your GitHub backup through klipper-backup. The tool registry keeps its last 10 versions in myrhino/registry_backups/. Photos live outside the config folder in ~/printer_data/rhino_data/images/, so they are not in the GitHub backup.

Tests. sh dev/run_all.sh runs a static check of the whole config and 583 automated checks: the macros in a simulated Klipper (against the real Mainsail macros); motion tests that follow where the bed and head go and run every macro and button from seven machine states with each toolhead against five safety rules; the portal, tool controls and macros, maintenance and the Admin lists; every portal screen opened in a real browser, with an accessibility scan and keyboard checks; and the installer run on a fake Pi. It needs pip install jinja2 flask (and Playwright for the browser test), and runs on every change pushed to GitHub. The simulator knows the travel limits, not the shape of your tools or stock, so every release also has on-machine checks - the plan is in docs/testing.md, and the ones for the current version are in Still to check on the machine.

Trying the portal without the printer. python3 dev/demo_server.py runs the portal against a copy of the config and a pretend Moonraker. Every screen in this manual can be tried there without touching the machine.

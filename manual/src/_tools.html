The tools

Every tool has a slot number. Slots 1–5 are the built-in tools defined in variables.cfg; tools you add in the Tool Manager get slot 6 and up.

SlotToolHardwareSet up a job withPower outputs
1BlockOneSingle-extruder print headSlicer start G-code (START_JOB)Hotend heater, fans
2SwitchFlyTwo filaments, one stepper, one nozzleSlicer start G-code (START_JOB)Hotend heater, fans, path servo
3LightSaber12 V 40 W blue diode laserLASER_JOB_SETUP FILE=<name>.gcodeLASER_INITIALIZE rail, SERVO_LASER intensity
4HotJoe24 V brushless spindle, ER8 colletCNC_JOB_SETUP FILE=<name>.gcodeSpindle_power relay, SPINDLE_SPEED ESC
5DragKnifeOstrich drag-knife holderDRAGKNIFE_JOB_SETUP FILE=<name>.gcodeNone
6+Your toolsPowered, passive or print-head cloneTOOL_JOB_SETUP FILE=<name>.gcode (clones use the slicer)Own pin or a shared output

Built-in tools are changed by editing variables.cfg. Tools you add are changed in the Tool Manager or with console commands, never by hand-editing custom_tools.cfg.

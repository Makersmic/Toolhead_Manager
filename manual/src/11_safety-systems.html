Safety systems

Each of these is automatic; none needs switching on.

  • Tool must match. START_JOB refuses a file sliced for a different tool. The laser and spindle commands refuse to fire unless LightSaber or HotJoe is the recorded tool, and switch their outputs off when they refuse.

  • Shared pin guard. SERVO_LASER is the laser's intensity signal on LightSaber and SwitchFly's filament servo otherwise; servo commands are blocked while LightSaber is mounted.

  • Power cap. An added powered tool never exceeds its cap, whatever M3 S or SET_TOOL_POWER asks for.

  • Watchdog. Every 5 seconds while an added powered tool is on: with no job running it is cut after the tool's Max time on; during a pause it is held off; if the tool is no longer mounted everything is switched off.

  • Everything off on the way out. Tool swap, CANCEL_PRINT, END_PRINT and EMERGENCY_STOP all switch off the laser rail and signal, the spindle relay (ESC to 0.3 neutral) and every added tool.

  • Pause makes it safe. See Pause, resume and cancel: lifted clear and powered off before parking.

  • Nothing changes mid-job. Tool swaps, adding/editing/removing tools and Klipper restarts from the portal are all refused while a job is printing or paused.

EMERGENCY_STOP is a power-off, not a halt. It cuts tool power but does not stop motion. To stop the machine dead, use Mainsail's emergency-stop button (M112), which shuts Klipper down; then FIRMWARE_RESTART.

Start low. Every starting power value (hot wire 40–50 %, caps, maximum on-times) is a placeholder. Test a new tool from a current-limited supply first, then raise its values in the portal while watching it.

Hardware layer. Heavy loads (laser, spindle, bed, vacuum pump) are switched through relays, so a controller fault cannot hold them on through the board itself. The spindle ESC's signal falls to neutral (0.3) and its relay opens if Klipper shuts down. Close the enclosure doors while the laser or spindle runs. Smoke detection is planned in the build notes but not yet fitted, so never leave a laser, hot-wire or spindle job unattended.

Running a job

Print jobs start from the sliced file. Every other tool starts from a guided setup that walks you through safety checks and setting the work zero, then starts the file for you.

Pick the material first (non-print tools): SET_TOOLHEAD TOOLHEAD=LightSaber MATERIAL=PLYWOOD. This applies the material's feed, power, acceleration and Z offset, and the setup wizards read it.

3D printing (BlockOne, SwitchFly, print-head clones)

  1. Slice with the Rhino profile. Its start G-code calls START_JOB TOOLHEAD="SwitchFly" MATERIAL="PLA" NOZZLE_SIZE=0.4 EXTRUDER=0.

  2. Upload and print from Mainsail as usual.

  3. START_JOB refuses to run if the file's tool does not match the mounted tool, then homes and shows a confirmation pop-up.

  4. END_PRINT switches off whatever tool is active and runs the staged BED_COOLDOWN.

Filament change mid-print: FILAMENT_CHANGE pauses, walks you through unload, load and purge, then resumes.

Laser (LightSaber)

Run LASER_JOB_SETUP FILE=<name>.gcode, then follow the pop-ups:

  1. Laser Job Setup – confirm ventilation, glasses, no PVC/vinyl, material flat, extinguisher nearby.

  2. Confirm Focus Height – then Focus OK – Test Fire makes a low-power mark.

  3. Check Test Mark – Yes to continue, No – Refocus to go back.

  4. Ready to Cut – add or remove passes, then Start Job.

CNC (HotJoe)

Run CNC_JOB_SETUP FILE=<name>.gcode:

  1. CNC Job Setup – safety confirmations.

  2. Set XY Work Zero – jog to the corner, then Set XY Zero and Move to Z.

  3. Set Z Work Zero – Use Automated 10mm Touch Plate (needs G38.2, see Still to check) or Set Manual Jog Zero Here.

  4. The spindle relay switches on and the ESC ramps to 40 %, then to your starting throttle.

  5. Ready to Cut – nudge the throttle ±5 %, then START JOB CUT NOW.

Drag knife (DragKnife)

Run DRAGKNIFE_JOB_SETUP FILE=<name>.gcode: verify the material and blade dial, set Z on the surface, cut a test mark, then Looks Perfect – Ready to Cut (or Bad Cut for blade-dial help) and DEPLOY ACTIVE CUT PASS.

Tools you added (slot 6+)

Run TOOL_JOB_SETUP FILE=<name>.gcode:

  1. <tool> Job Setup – the checklist you wrote in the portal; All Confirmed.

  2. Set Work Zero – Set X/Y zero here, then Set Z zero here with the tool tip on the surface; Continue.

  3. Ready to start – Test pulse fires briefly at low power; then Start – tool power ON (power on for the whole file) or Start – file controls power (the file's own M3/M5 switch it). Passive tools just show Start.

M3 S<value> / M5 in any file control whichever tool is mounted: the laser, the spindle or your powered tool. S is scaled against that tool's S value for full power and never exceeds its power cap.

Slicer and CAM settings

OrcaSlicer (printing). The printer profile's start G-code must call START_JOB with the tool, material, nozzle size and extruder, for example START_JOB TOOLHEAD="SwitchFly" MATERIAL="PLA" NOZZLE_SIZE=0.4 EXTRUDER=0. End the file with END_PRINT.

LaserWeb 4 (laser). Use these machine settings. They replace the older ones in the repository's Laserweb Setup note, which drove pins (LASERPOWER_pin, VACPUMP_pin) that no longer exist; going through M3/M5 keeps the laser lockout, the pause handling and the power scaling.

LaserWeb fieldValue
Gcode StartG21 and G90 – homing, focus and work zero are done by LASER_JOB_SETUP
Gcode EndM5
Gcode Homingleave blank

Tool OffM5
Laser IntensityM3 S

PWM MAX S VALUE1000 (matches laser_s_max in variables.cfg)

Drag-knife files must not contain M3: it is refused while the DragKnife is mounted. Use a separate LaserWeb profile with Laser Intensity and Tool Off left blank.

CNC files. Spindle speed is set in CNC_JOB_SETUP (the throttle buttons), not by M3 S. An M3 in the file leaves a running spindle alone; M5 at the end stops it.

Still to check on the machine

These could not be tested without the printer.

  • First pause and resume of each tool type – confirm the 10 mm lift clears your work and the spindle spin-up is long enough before it re-enters the cut.

  • Idle timeout – add [idle_timeout] timeout: 1800 if you use the full ABS/ASA cooldown.

  • Connector pins – only PB1, PC0 and PC1 are free; if the umbilical carries other spare pins, list them in myrhino/umbilical.json.

  • LEDFLASH blocks for about 1.35 s each time it runs, which also delays the macros that call it (cancel, emergency stop).

  • Power values – tune every placeholder power and on-time on the real tools.

  • Spindle shutdown value. SPINDLE_SPEED used to fall to full throttle (1) on a Klipper shutdown; it now falls to 0 (no signal; Klipper only allows 0 or 1 here), and the spindle relay opens. After the next emergency stop with HotJoe mounted, confirm the ESC stays quiet.

  • LaserWeb settings. Run the first file made with the settings in Slicer and CAM settings at low power before a real cut.

  • Z travel. gear_ratio is 2:1 on all three Z steppers. After any update, jog Z 10 mm and measure it, then run Z_TILT_ADJUST before the next job.

  • Set Z zero after a restart. With a non-print tool mounted, restart Klipper with the bed parked, run SET_Z_ZERO and answer Yes: the bed should not move until you press a Bed button, and X/Y home normally. Klipper needs [force_move] enable_force_move: True (added in toolchanger.cfg).

Job setup and Preview

Job setup turns a model or drawing into a job for the Rhino in five steps: File, Process, Setup, Preview and Job file. The steps run along the top of the page. Once the file and the process are chosen, you can go back and forth between Setup, Preview and Job file in any order without losing anything. Going back to File starts over.

1 · File

Drop a file on the page, or click to choose one. Job setup takes:

  • 3D models: STL, 3MF and OBJ, for printing or milling;
  • 2D drawings: SVG and DXF, for the laser and the knife;
  • ready-made G-code from another program such as OrcaSlicer or LightBurn. It is checked line by line, the same as a file Studio makes.

Drop several models, or several drawings, at once and they become the parts of one job, set side by side. The first file decides the kind; files of the other kind, G-code and files that can't be read are skipped and listed with the reason. Below the drop area, Or start from a toolhead shows each tool with the files, size and materials it takes.

2 · Process

Studio shows the model turning slowly (drag to turn it yourself) and asks What should the Rhino do with it? It lists what each toolhead could do with the file, with the mounted tool marked. Pick one and press Continue. CNC milling takes one part at a time, so it isn't offered for a job with several parts.

3 · Setup

The part sits on the bed in 3D, with the tool, material and settings beside it.

  • Placing the part. Drag it to move it; drag empty space to turn the view; scroll or pinch to zoom. Angle, Top and Fit part or Whole bed reset the view. Under the bed, Centre X and Centre Y, Turn, Tilt and Scale take exact values; Turn 90°, Turn on X and Turn on Y turn it round the bed's axes; Lay flat then a click on a face puts that face down (Esc cancels).
  • Warnings appear in words: off the bed, too tall, in a keep-out area, over the prime line. The checks in step 5 judge the finished file again.
  • Several parts. Add file, in the header over the bed, or a file dropped on the bed, adds a part. Once there are two, a list of parts appears beside the bed. Click a part, on the bed or in the list, to select it: the fields and the arrow keys then work on that part. Right-click a part (long-press on a phone) for Duplicate, Lay this face flat, Reset way up and Delete from job. Parts that overlap give a warning but aren't stopped. All parts share the settings and are prepared as one file.
  • Toolhead and material. The tool chosen in step 2, and its material and nozzle from the tool's table. The material sets the temperatures, which START_JOB heats to.
  • Settings. A profile (the built-in one, or one you saved with Save as new; Reset goes back to it), then the settings for the process. For printing, choose the slicer: PrusaSlicer on the Rhino, or Kiri:Moto in this browser. The main settings sit on top; the folded groups below hold the rest.

Supports where you choose

Supports can be Off, Automatic, or Only where I mark. With Only where I mark, press Mark supports and point at the part: a ring shows where support would go, on the overhang below the pointer. Click to place a mark at the Mark reach size (1 to 15 mm), or press and drag to size it. Click a mark to select it, then change its reach, or remove it with Remove or the Delete key. Erase marks wipes the marks you drag over, and Clear marks removes them all. While supports are on, overhangs steep enough to need them are tinted amber. Marks are kept with that file's job, and stay on the same spot if you move or turn the part. No marks means no support, and the screen says so.

Marks are painted on the underside of the part. To see them, look from below: Settings › Appearance › 3D view sets how see-through the bed is from underneath.

4 · Preview

Preview prepares the file if anything has changed, then draws every move. Drag to turn it, and scroll or pinch to zoom. Angle, Top and Whole bed reset the view. The layer slider shows the layers up to that point, with the current one strongest. The move slider steps through that layer. Show travel moves adds the moves that don't print or cut. Printed lines are drawn at their real width; supports are drawn in a different shade from the model.

Preview draws the file, not the macros it calls: a prime line or anything else a macro moves isn't shown. A laser left on during a travel move is drawn as cutting, because the machine really would move with it on. On a slow computer, tick Lighter drawing under the drawing to simplify it; the file isn't changed.

5 · Job file

The file's time, filament or cutting length, layers and where it sits on the bed, then the checks it has passed: that it's for this toolhead, has nothing that homes, swaps tools or restarts, ends with END_PRINT, stays inside the bed, under the Z limit and clear of the lead screws, keep-out areas and the prime line. The tool's start and end G-code, if it has any, is named at the top, with a link to change it on the tool's page.

  1. Press Send to Rhino. The file goes to the Rhino's job files and nothing starts: Sent as … appears.

  2. Press Start job beside it. Studio checks the mounted tool matches and Klipper is ready, shows any maintenance that is due, and asks first. If a different tool is mounted, it offers Swap to … instead.

  3. Once the job starts, Studio opens Control, where the job's questions and live tuning are.

Download saves the file to your computer instead. While a job is running there is no Start button: start the next one from Files when the bed is clear. Nothing queues, on purpose, so a job can't print onto a finished part.

Laser, CNC and knife jobs open Studio's start wizard, which walks you through the safety checks, the zero, a frame check and a test before the file runs (see Running a job). Added tools start through their setup pop-ups on Control.
